Inspection Document Parser

Turns dense inspection-report PDFs into structured data: tables (including borderless element / rating / comment tables), fillable form-field values, and text, with repeated banners and header blocks removed.

Demo service. Please don't upload confidential documents. Files are deleted as soon as they're parsed and nothing is stored.
